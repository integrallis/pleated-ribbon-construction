# Submitting to SEA 2027: step-by-step

Venue: 25th Symposium on Experimental Algorithms (SEA 2027), Karlsruhe Institute of Technology,
21–23 July 2027. https://sea2027.iti.kit.edu/

**Format authority.** SEA publishes in LIPIcs. The official author page is
https://submission.dagstuhl.de/series/details/LIPIcs#author (linked from the SEA 2026 call). Its
requirements, read on 2026-10-07, are built into `scripts/make_lipics.py`:

- class `lipics-v2021` (v2021.1.3), compiled with pdfLaTeX, class defaults untouched (line
  numbers stay on; no font, spacing or colour changes);
- only the class's sectioning macros (run-in headings become `\subparagraph*`);
- BibTeX with the `plainurl` style, numeric citations, no `natbib`;
- mandatory metadata: `\title` and `\titlerunning`, one `\author` per author, `\authorrunning`,
  `\Copyright`, `\ccsdesc`, `\keywords`, the abstract, and `\relatedversion` once the arXiv
  version exists;
- an affiliation with at least city and country: "Integrallis Software, Scottsdale, Arizona, USA";
- one article file with only the content to be published, and no overfull boxes or BibTeX warnings;
- "main-text pages" are everything except the title page (title, authors, affiliations, abstract)
  and the bibliography, with a stated flexibility of plus or minus one page;
- LIPIcs follows Dagstuhl Publishing's generative-AI policy: authors are responsible for the
  content, AI tools cannot be authors, and substantive use of such tools must be declared. That
  is the publisher's rule and applies in addition to whatever the SEA 2027 call says.

**Status of the rules (checked 2026-10-07):** the SEA 2027 site shows "TBD" for the submission
deadline, the notification date and the call for papers. Everything below marked *2026 rule* is
what the SEA 2026 call required (https://sea2026.github.io/cfp, read directly) and is a precedent,
not a 2027 rule. Step 1 is therefore to recheck when the call appears.

## 1. When the call is published, check these seven things

1. Deadline and time zone (2026: anywhere on Earth).
2. Page limit (2026: 12 pages excluding bibliography and the front page, plus an appendix of up to
   5 pages; figures and tables in the appendix count toward the 5).
3. Format (2026: LIPIcs LaTeX class, default values unchanged, no font-size options).
4. Anonymity (2026: double-blind; a non-anonymized paper is desk-rejected).
5. Software links (2026: no link to your own GitHub; link anonymously, for example a file-share
   link; the public link goes back in for the proceedings version).
6. Preprints (2026: arXiv and talks allowed; the submission may say a public version exists but
   must not link or cite it).
7. The policy on text generated by large language models (2026: not allowed except for plots
   from experimental data and polishing text the authors personally wrote, with a declaration
   at submission). Check the revised manuscript against the 2027 wording before submitting.

If any of these changed, tell the tooling what changed before building the submission; the page
limit and the class options are the two that affect the build.

## 2. Build the submission PDF

```bash
cd ~/Code/ribbon-catches-bloom            # the repository
python3 scripts/make_lipics.py            # regenerates paper/sea/main.tex (anonymous) from paper/main.tex
cd paper/sea && latexmk -pdf main.tex     # use pdfLaTeX, not tectonic, for the page count
```

Then check, in `paper/sea/main.pdf`:

- **Page budget.** As of 2026-10-07 the build is 17 pages: the main text ends at the bottom of
  page 12 and the title-page material takes about two thirds of page 1, so the main text is
  about 11.4 pages against a limit of 12; references follow; the appendix is about 3.5 pages
  against a limit of 5. Re-count after every edit. A copy of this build is in
  `dist/sea-anonymous-preview.pdf`.
- **Anonymity.** The first page must say "Anonymous author(s)". Search the PDF for "Sam-Bodden",
  "Integrallis", "integrallis" and "github.com/integrallis"; there should be no match. The
  generator removes the author block, the repository URL and the sentence linking the crate; it
  does not scrub anything else, so read the acknowledgements-style "Artifacts" paragraph once.
- **Self-citation.** The paper does not cite earlier work of yours, so nothing needs rewording
  into the third person. The 2026 call said key references must not be omitted for anonymity.
- **Class defaults.** The submission build keeps line numbers and the LIPIcs frame, as the
  class ships them. Only `scripts/make_lipics.py --arxiv` turns them off, for a preprint.
- **Log.** `latexmk` should finish with no undefined references, no overfull boxes and no BibTeX
  warnings; that is the state on 2026-10-07.

## 3. Build the anonymous artifact

```bash
scripts/make_anonymous_bundle.sh          # writes anonymous-artifact.tar.gz from the committed tree
```

- Read the "remaining matches" list it prints. On the last run it listed mentions of the
  predecessor project, a course name and a home-directory path in a few files; decide for each
  whether it identifies you and edit or accept.
- Upload the tarball somewhere that does not reveal you (the 2026 call suggested a file-share
  link) and put that link in the submission where the paper says the artifact link is withheld.
- Do not link `github.com/integrallis/pleated-ribbon-construction` or the `pleat` crate in the
  submission.

## 4. Submit

- Use the submission system named in the 2027 call (not yet announced).
- Title: Pleated Ribbon Construction: Approximate Sorting Recovers the Locality of a Full Sort
- Abstract: paste from `dist/arxiv-metadata.txt` (plain text; rebuild it with
  `scripts/make_arxiv_bundle.sh` if the abstract changed).
- Keywords: ribbon filter, approximate membership, filter construction, cache locality,
  algorithm engineering.
- Topics: algorithm engineering; data structures; hashing and filters, as the form offers.
- **Conflicts of interest.** Declare anyone on the program committee who has seen the draft or
  corresponded with you about it. If the outreach email went to Peter Dillinger and Stefan
  Walzer, declare both; Peter Sanders is a local organiser of SEA 2027.
- **Public version.** If the arXiv version is up, the 2026 rule let you say so in the submission
  without a link, or tell the chairs privately.
- **Declarations.** Answer the generative-AI declaration, if there is one, according to how the
  submitted text was actually written.
- Do not submit the same paper to another refereed venue while it is under review here.

## 5. After submitting

- Do not post a new arXiv version or publicize the paper if the 2027 call asks for that during
  review (the 2026 call did not restrict it).
- If accepted: build the named version with `python3 scripts/make_lipics.py --named`. It
  carries your name, "Integrallis Software, Scottsdale, Arizona, USA", your email and your ORCID
  iD (https://orcid.org/0009-0007-4515-1979), and restores the repository and crate links. Add
  `\relatedversion` with the arXiv URL and the DOI and Software Heritage identifier through
  `\supplementdetails`. The camera-ready LaTeX sources are uploaded to Dagstuhl's Submission
  Server at the editors' invitation; Dagstuhl typesets them and asks you to approve a PDF preview
  and the extracted metadata, usually within three working days. Plan to present in person. LIPIcs charges authors
  nothing; registration was 4,200 DKK early in 2026.
- If rejected (about 31 March): the fallback in the plan is the ESA 2027 engineering track
  (2026 dates: abstract 21 April, paper 23 April; single-blind), then ALENEX 2028 (2027 edition's
  deadline was 20 July). Neither call is published yet.

3. Tag a release and archive it (Zenodo DOI, Software Heritage ID); add both to the paper and
